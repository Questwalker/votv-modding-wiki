# Creating your mod
Creating a Lua mod is the easiest of all other modding methods and requires pretty much no set up. That being said, it's heavily recommended to use a code editor just to make the process of development easier.

I recommend using Visual Studio (or it's sibling VSCodium) and the Lua extension by Tencent or sumneko. The extension by Tencent is older, but is faster and has less bugs, while the sumneko one is more up to date.

## Where to create your script
To find the correct location for youur script, you will need to find the location of your installation's `mod` or `Mods` folder. Follow the following directions based on your modding installation.

<Tabs groupId="installing-victorybp">
<TabItem value="local-install" label="In a mod manager" default>
Go into your mod manager's settings, and search for the button "Browse profile folder". This will open a folder in your file explorer, and from there navigate into the `shimloader` folder, and into the `mod` folder.
</TabItem>
<TabItem value="global-install" label="In a manual installation">
Go to the location of your download of VotV, then navigate to the `/VotV/Binaries/Win64/ue4ss/Mods` directory.
</TabItem>
</Tabs>

## Creating your mod's folder
Once you are in your mod folder, you will see some other files and folders such as "BPML_GenericFunctions". Create a new folder and give it the name of your mod.

Once you have done that, enter that folder and create a folder named `scripts`, and inside that folder create a new file called `main.lua`. This is your mod's script!

Finally, to enable your mod, you can either:
* (Recommended) Create a blank `enabled.txt` file in your mod folder (alongside your `scripts` folder). This force-enables the mod.
* Add a line of text like `<My modname> : 1` to the `mods.txt` file in the base mod folder. Make sure to place your text **before** the `keybinds : 1` line.

```
📂 mod/Mods
    📁 MyExampleMod
        📁 scripts
            📄 main.lua
        📄 enabled.txt
```

## Next steps
Now that you have your script file, you can start programming your mod. Open it up in your editor and you're ready to start programming. To run your mod, all you have to do is run the game and the script should run automatically.

I heavily recommend checking out [UE4SS's lua modding docs](https://docs.ue4ss.com/dev/lua-api.html) for some extra insight on the API, and also check out the [Palworld modding wiki](https://pwmodding.wiki/) for more examples and in-depth guides on Lua usage.
